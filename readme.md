Особенности проекта:
Расширяемость: Новые типы спанов можно добавлять через rules_config.json или программно через RuleManager.add_span_type()

Два уровня правил: Спецификация (структурные требования) и семантика (логические требования)

Детальный вывод: Таблица с полным анализом сохраняется в файл, краткая сводка выводится в консоль

Валидация типов: Проверяются не только названия тегов, но и их типы данных

Семантические ограничения: Можно задавать допустимые значения для тегов (например, HTTP методы)
